> **`urotsuki` ≈ うろつき / 彷徨き**  
> Someone who wanders around without staying in one place for very long.  
> Not much of a brand story, but it does explain this GitHub account pretty well.

CPU, cryptography, agent safety, slightly unnecessary developer tools — I get curious, wander in, learn enough to make something, and eventually wander somewhere else.

The repositories are probably a better bio than a bio.

## 足跡 / Places I've wandered into

**[VICTORY-V](https://github.com/urotsuki-san/VICTORY-V)** — CPUまで来てしまった。  
A home-grown processor family. `VV32-A0` is the working starting point, with capability-checked memory, explicit commit/rollback, and a path toward `VV64-A0`.

**[OrIsyVra](https://github.com/urotsuki-san/OrIsyVra)** — 暗号にも迷い込んだ。  
Experimental authenticated encryption in Rust, with a file-encryption application attached because stopping at the algorithm felt unfinished.

**[AperiSyVra](https://github.com/urotsuki-san/AperiSyVra)** — そのまま公開鍵側まで行った。  
Aperiodic hidden-code KEM research. Working prototype first; cryptanalysis very much still welcome.

**[THYROROS](https://github.com/urotsuki-san/THYROROS)** — AIを放っておくのが少し怖くなった。  
A small gatekeeper for autonomous agents: contracts can narrow authority, but they do not get to quietly invent more of it.

**[tsundere-linter](https://github.com/urotsuki-san/tsundere-linter)** — 普通のlint結果では味気なかった。  
Real Python AST checks, delivered with completely unnecessary attitude.

**[dependency-horoscope](https://github.com/urotsuki-san/dependency-horoscope)** — 依存関係まで占い始めた。  
Dependency health disguised as a daily fortune. Sometimes 「大凶」 is useful information.

## うろついても持っていくもの

The subject changes a lot. A few habits do not.

I like odd premises, but I want them to actually run. If something can be tested, I would rather test it than describe how well it should work. If a project says **experimental**, that word is there on purpose.

Failures should be visible. Rollback is useful. Weird names are fine; weird claims need evidence.
